# KD Works website (kdworksllc.com)

A simple static site. No build step, no frameworks.

## Files
- `index.html` — all of the page text and layout
- `styles.css` — colors, fonts and spacing (KD Works brand kit)
- `assets/` — logo files (from the KD Works Brand Kit in Drive) and favicon

## Changing the words
Open `index.html`, find the text you want, edit it, and save. Sections are marked with comments (HERO, SERVICES, HOW WE WORK, PRINCIPLES, ABOUT, CONTACT). The contact email `info@kdworksllc.com` appears in a few places, so search for it if it ever changes.

## Publishing safely
1. Make your edit on a branch (or ask Claude to make it and open a pull request).
2. Vercel posts a private preview link on the pull request. Check it there.
3. Merge the pull request into `main` to publish to kdworksllc.com.
You can undo any change from the history.

## Brand notes
Always write the name as "KD Works". Colors: linen #F6F3EC, harbor navy #1E3A5F, ink #1A2230, brass #C08A2E (one rule per page). Fonts: Fraunces for headlines, IBM Plex Sans for everything else. Never retype the logo; use the files in `assets/`.
